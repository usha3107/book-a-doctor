# 🩺 Book A Doctor

A modern and user-friendly **Doctor Appointment Booking System** that allows patients to find doctors, book appointments, and manage their healthcare appointments online. The application provides a seamless experience for both patients and administrators through an intuitive interface.

---

## 📌 Overview

Book A Doctor is designed to simplify the appointment booking process between patients and doctors. Instead of waiting in long queues or making phone calls, users can search for doctors, view their profiles, check availability, and book appointments in just a few clicks.

---

## ✨ Features

### 👤 Patient Features

- User Registration & Login
- Secure Authentication
- Browse Available Doctors
- Search Doctors by Name/Specialization
- View Doctor Profiles
- Book Appointments
- View Appointment History
- Cancel Appointments
- Update User Profile

### 👨‍⚕️ Doctor Features

- Doctor Profile Management
- View Scheduled Appointments
- Manage Availability
- Update Personal Information

### 🛠️ Admin Features

- Manage Doctors
- Manage Patients
- View All Appointments
- Dashboard Overview
- Monitor System Activities

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/usha3107/book-a-doctor.git
```

Navigate to the project

```bash
cd book-a-doctor
```

---

### Install Dependencies

#### Backend

```bash
cd server
npm install
```

#### Frontend

```bash
cd client
npm install
```

---

## ▶️ Run the Application

### Start Backend

```bash
npm run server
```

or

```bash
npm start
```

### Start Frontend

```bash
npm start
```

---

## 🔐 Environment Variables

Create a `.env` file inside the server directory.

Example:

```env
PORT=5000

MONGO_URI=your_mongodb_connection_string

JWT_SECRET=your_secret_key

NODE_ENV=development
```

## 🔄 Workflow

1. User registers or logs in.
2. Browse available doctors.
3. Search by specialization.
4. View doctor details.
5. Book an appointment.
6. Appointment gets saved in the database.
7. User can manage booked appointments.
